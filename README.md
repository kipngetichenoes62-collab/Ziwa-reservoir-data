# Ziwa Reservoir Data

This repository contains environmental, ecological, and spatial data collected for the Ziwa Reservoir project.

## Repository Contents

### 1. Land Use / Land Cover (LULC)
* **File:** `Enoes LULC.docx` 
* **Description:** Contains qualitative descriptions, historical context, or narrative reports regarding land use and land cover changes around the reservoir catchment area.

### 2. Environmental & Ecological Monitoring
* **File:** `ZiwatadpoleWaterQuality.xlsx`
* **Sheets/Tabs Included:**
  * **Water Quality:** Physio-chemical parameters and nutrients (e.g., pH, temperature, dissolved oxygen, turbidity,total nitrogen, total phosphorous,nitrites, nitrates and ammonia).
  * **SVL (Snout-Vent Length):** Morphometric measurements tracking body length variations in local amphibian or reptile populations.
  * **Time to Metamorphosis:** Developmental timeline data tracking larval stages to maturity.
  * **Abundance:** Population counts and species density monitoring over time.
